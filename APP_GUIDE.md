# 🎵 StraemGab - Guia Completo

## Bem-vindo ao StraemGab!

StraemGab é um **soundboard PWA** (Progressive Web App) - funciona como um app nativo em qualquer dispositivo!

---

## 📱 Como Usar

### Instalação no Navegador

#### **Windows/PC:**
1. Abra o site no Chrome, Edge ou Brave
2. Clique no botão **"Instalar App"** (canto superior esquerdo)
3. Escolha **"Instalar"** na janela que aparecer
4. O app será adicionado ao seu menu iniciar

#### **Android:**
1. Abra no Chrome
2. Clique em ⋮ (menu) → **"Instalar app"** ou **"Adicionar à tela inicial"**
3. O app aparecerá na sua tela inicial

#### **iOS (iPad/iPhone):**
1. Abra no Safari
2. Clique em **Compartilhar** → **Adicionar à Tela Inicial**
3. Nomeie como "StraemGab" e toque em **Adicionar**

## 🎮 Funcionalidades Principais

### Botões de Som
- **12 botões** com sons personalizados
- **Clique** para reproduzir
- **Atalhos de teclado:** 1-9, 0, -, +

### ⚙️ Ajustes

#### **Aba Geral**
- **Volume**: Controlar volume global (0-100%)
- **Cor do Botão**: Personalizar cor quando o botão está tocando
- **Imagem**: Adicionar imagem de fundo ao botão selecionado
- **Áudio Personalizado**: Trocar o som de um botão
- **Ação ao Pressionar**: 
  - Tocar som (padrão)
  - Abrir link (Discord, YouTube, etc.)

#### **Aba Microfone**
- Habilitar microfone para usar com o app
- Selecionar qual microfone usar
- Atualizar lista de microfones

#### **Aba Atalhos**
- Configurar teclas personalizadas para cada botão
- Padrão: 1-9, 0, -, +

✅ **Armazenamento Local** - Seus ajustes são salvos

## 💾 Dados Salvos

Todos os dados são armazenados localmente no seu dispositivo:
- Áudios personalizados
- Imagens dos botões
- Cores escolhidas
- Configurações de atalhos
- Volume

**Nenhum dado é enviado para servidor!**

## 🔧 Dicas de Uso

### Para Streamers
1. Configure atalhos de teclado para rápido acesso
2. Adicione emojis ou imagens em cada botão
3. Use ações personalizadas para abrir links de doações

### Para Gaming
1. Personalize sons de reação
2. Configure atalhos para mão livre
3. Teste áudios em diferentes volumes

### Otimizando Performance
- Manter volume entre 60-80% para áudio limpo
- Usar áudios curtos (< 3 segundos)
- Fechar outras abas quando usar em stream

## 🐛 Troubleshooting

**Botão não funciona?**
- Verifique o volume
- Tente recarregar a página (F5)
- Verifique a conexão de internet

**Áudio personalizado não salva?**
- Verifique o tamanho do arquivo (máx 5MB)
- Tente outro formato (MP3 recomendado)
- Limpe o cache do navegador

**App não instala?**
- Use Chrome, Edge ou Brave (não funciona em Firefox/Safari completo)
- Atualize o navegador
- Tente em navegação privada
