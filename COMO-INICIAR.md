# 🚀 Como Iniciar o StraemGab

## Opção 1: Forma Mais Simples (Recomendado)

### Clique 2x em `iniciar-server.bat`

Pronto! O app vai:
1. ✅ Iniciar o servidor
2. ✅ Abrir automaticamente no navegador
3. ✅ Ficar rodando em background

## Opção 2: Criar Atalho no Desktop

### Execute `criar-atalho.vbs` (uma única vez)

Após isso, você pode:
- Clique duplo no atalho "StraemGab" do Desktop
- Sempre vai iniciar de forma rápida

## Opção 3: Linha de Comando

```cmd
python server.py
```

Depois acesse: http://localhost:8000

- Python 3.8+ instalado

---

## 🆘 Problemas Comuns

**"Python não encontrado"**
- Instale Python em https://python.org
- Marque "Add Python to PATH" na instalação

**"Porta 8000 em uso"**
- Feche outra instância do StraemGab
- Ou reinicie o computador

**Navegador não abre**
- Abra manualmente: http://localhost:8000
- (Pode variar em alguns sistemas)
